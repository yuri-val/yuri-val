## 👨‍💻 About me

- 🏢 Engineer at **Softo**. I build and run business platforms on **Ruby on Rails** and **React**, from the database to the deploy.
- 🤖 I put **LLMs to work in real products**: document reading, RAG chatbots, in-app assistants with tool calling, and AI steps in CI.
- 📱 I publish my own apps: **[Generator Tracker](https://generatortracker.yuri-val.dev/)** (iOS, Android, web) and **[Mova](https://mova.yuri-val.dev/)** (macOS).
- ⚙️ I maintain several **GitHub Actions** on the Marketplace that write PR descriptions, open release PRs and ship Docker images.
- 🏠 After hours: **Home Assistant**, ESP32 and ESPHome for my home solar setup, and a 3D printer that is never idle.
- 💬 Ask me about Rails, React, legacy Rails upgrades, CI/CD, Docker, or shipping an Expo app to both stores.
- 💪 Open to **freelance work** and collaboration.

## 🧭 How I work

- **Tests first.** A failing test, then the fix, then the full suite green.
- **Small pull requests.** One task, one branch, a description a reviewer can read in a minute.
- **Automate the boring parts.** Changelogs, release notes, PR descriptions and image builds run in CI, not by hand.
- **Write it down.** Manuals, runbooks and decision notes live next to the code.
